## Welcome to the Main Software Package for Virginia Tech AutoBoat

**Current Documentation and Installation Instructions**:
<https://autoboat-vt.github.io/documentation>

<br>

To install the prebuilt binaries for deployment, please run:

```bash
curl -sSL https://raw.githubusercontent.com/autoboat-vt/autoboat_vt/main/install.sh | sudo bash
```
